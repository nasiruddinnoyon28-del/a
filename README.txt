MD. NASIR UDDIN NOYON — FULL PORTFOLIO WEBSITE

Included:
- index.html (complete HTML, CSS and JavaScript in one file)
- assets/portfolio-banner.png (your supplied portfolio banner image)

How to run:
1. Extract the ZIP file.
2. Keep index.html and the assets folder together.
3. Open index.html in Chrome.

Before publishing:
- In index.html, replace every occurrence of your-email@example.com with your real email address.
- Add your real LinkedIn, Facebook or other social links if you want them.
- Replace concept projects with genuine portfolio samples as you complete them.
- Skill-bar percentages are illustrative and should be updated to match your progress.

Features:
- Responsive navigation and mobile menu
- Futuristic AI / neon / glassmorphism styling
- Animated portrait ring and subtle 3D pointer tilt
- About, skills, focus areas, concept projects, learning journey and contact sections
- Project filters, scroll reveal and animated skill bars
- Contact form creates an email draft (no backend and no message storage)

This is a local front-end website. It is not deployed online yet.
